# packages/rin-ui

Owner: Frontend design system.

Boundary: TailwindCSS 4 tokens, shadcn/ui wrappers, Rin visual identity, motion primitives, accessibility defaults, mascot assets, and plugin mount surfaces.

## Current Skeleton

- `rinTokens` centralizes the Sakura/Sky/Lavender palette.
- `RinMascot` provides the first self-drawn SVG mascot asset.
- `cx` keeps class composition local until the full shadcn/ui wrapper layer lands.
